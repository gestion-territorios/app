# Gestión de Territorios · Android

App para organizar la predicación del territorio de la congregación: los capitanes registran las cuadras de cada
salida y los encargados asignan los territorios.

## Descargar
**[territorios.apk](https://github.com/gestion-territorios/app/releases/latest/download/territorios.apk)**: la versión
más reciente, siempre en este mismo enlace.

## Instalar
1. Abre el archivo descargado (en la notificación o en la carpeta Descargas).
2. Si Android pide permiso para instalar apps de esa fuente, toca **Configuración**, activa **Permitir de esta fuente** y vuelve atrás.
3. Toca **Instalar** y entra con tu cuenta de Google.

La app se actualiza sola al abrirse. En iPhone o en el computador se usa la versión web:
https://territorio-el-carmen.web.app

Este repositorio solo guarda las descargas; no contiene código ni datos.
